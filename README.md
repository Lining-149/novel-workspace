# 小说写作仓库

用 GitHub 管理小说，支持版本回溯、多设备同步、Markdown 写作。

## 目录结构

```
github-novel/
├── README.md          # 本说明
├── chapters/          # 正文章节，每章一个文件
│   └── 第001章.md
├── outline/           # 大纲与设定
│   ├── 故事大纲.md
│   ├── 世界观设定.md
│   └── 人物设定.md
└── materials/         # 素材、灵感、参考资料
    └── 素材库.md
```

## 写作规范

- 每章正文 2000-3000 字，单独一个文件，按 `第NNN章.md` 命名
- 章节标题用一级标题：`# 第001章 章节名`
- 正文以白描为主，短句、口语化对话
- 重要改动用 Git 提交，方便随时回退

## 常用 Git 命令

```bash
# 写完一章后提交
git add .
git commit -m "完成第001章"
git push

# 换设备后先拉取最新内容
git pull
```
